# UI · Avatar with Image

## `components/DevCard.tsx`

1. Add `Image` to the import:

```tsx
import { View, Text, Image, Pressable, StyleSheet, Linking } from 'react-native';
```

2. Replace the name/username `<View>` inside the header:

```tsx
<View style={styles.identity}>
  <Image source={{ uri: avatarUrl }} style={styles.avatar} />
  <View>
    <Text style={styles.name}>{dev.name}</Text>
    <Text style={styles.username}>@{dev.username}</Text>
  </View>
</View>
```

`avatarUrl` and the `identity` / `avatar` styles already exist in the file.
