Library Compatibility.
Not every npm package works in React Native.
What it looks like

You install an npm package, it works fine on web, then fails in Native with undefined is not an object — or it installs but silently does nothing.

Why it happens

Web libraries often rely on document, window, or other browser APIs that don't exist in React Native. There's no DOM — only the native bridge.

How to evaluate a library before using it 
// Look for "react-native" in the package's keywords
// or as a peerDependency — that's the signal it's safe.

// Common replacements:
react-router   →  react-navigation
localStorage   →  AsyncStorage
react-modal    →  Modal (built-in RN)
styled-comps   →  StyleSheet / NativeWind

// These work directly — no changes needed:
fetch()   date-fns   lodash   zod   zustand
