Workshop 02 · Troubleshooting
Works on one OS. Breaks on the other.
What it looks like · why it happens · how to fix it. Five cases, all from Card Vault.
🌗
01 · utils/platformShadow.ts · GlowHalo.tsx
Shadows and glow.
There is no box-shadow in React Native.
What it looks like
iOSA golden glow around the Legendary card.
AndroidA flat gray smudge. No color, no blur.
Why it happens

iOS has four props: shadowColor, shadowOpacity, shadowRadius, shadowOffset. Android has one: elevation. It ignores radius and opacity, and shadowColor only tints it on API 28+.

Android also draws elevation only if the view has an opaque backgroundColor.

How to fix it 
// 1. Each OS gets its own style
Platform.select({
  android: { elevation: radius, shadowColor: color },
  default: { shadowColor: color, shadowOpacity: 0.85, shadowRadius: radius,
             shadowOffset: { width: 0, height: 0 } },
})

// 2. Same glow everywhere: stack translucent rounded Views
<View style={{ position: 'absolute', top: -spread, left: -spread, ... }} />

02 · components/card/CardView.tsx
overflow: hidden eats the shadow.
Rounded corners that clip the shine also clip the glow.
What it looks like

You add overflow: 'hidden' so the shimmer respects the rounded corners. On iOS the glow vanishes. Android looks fine.

Why it happens

On iOS the shadow is drawn outside the view's bounds. overflow: 'hidden' clips everything outside — including the view's own shadow.

How to fix it 
// Two layers. One casts the shadow, one clips the content.
<View style={[ size, radius, backgroundColor, glowShadow(...) ]}>   // outer: overflow visible
  <CardFrame style={{ flex: 1 }} ...>                       // inner: overflow hidden, clips
    ...card face and effects...
  </CardFrame>
</View>
📱
03 · components/Screen.tsx
The status bar covers my header.
SafeAreaView is iOS-only.
What it looks like
iOSTitle sits below the notch.
AndroidTitle is drawn under the clock and battery icons.
Why it happens

The SafeAreaView from react-native only adds padding on iOS. Android draws content edge to edge under the status bar.

How to fix it 
paddingTop: Platform.OS === 'android' ? (StatusBar.currentHeight ?? 0) : 0

// Production apps: react-native-safe-area-context (works in Expo Go)

04 · theme/tokens.ts · CardFace.tsx
Fonts and emoji.
Same code, different typography.
What it looks like

The card title uses a different face on each phone. A font name you set simply does nothing on the other OS. On Android the big creature emoji is cut off at the top or bottom.

Why it happens

System font names are per-OS: Avenir Next and Menlo exist on iOS only; sans-serif-condensed and monospace on Android only. There is no fallback stack like in CSS. Android also adds extra font padding that crops large glyphs.

How to fix it 
fonts = {
  heading: Platform.select({ ios: 'Avenir Next', android: 'sans-serif-condensed', default: 'System' }),
  mono:    Platform.select({ ios: 'Menlo',        android: 'monospace',            default: 'monospace' }),
}

// Big emoji on Android:
emoji: { fontSize: 84, lineHeight: 104, includeFontPadding: false, textAlign: 'center' }
🎞️
05 · hooks/usePulse.ts · ShimmerSweep.tsx
Animation limits.
Two small traps that cost an hour each.
What it looks like 
Error: Style property 'width' is not supported by native driver.

// and: the shimmer has a dirty gray edge on iOS
Why it happens

useNativeDriver: true runs on the UI thread, but it only supports transform and opacity. Layout props and colors are not supported.

In a gradient, 'transparent' means transparent black on iOS, so the fade passes through gray.

How to fix it 
// Build effects from transform + opacity only
Animated.timing(value, { toValue: 1, useNativeDriver: true })

// Fade to the SAME color with alpha 0
colors={['rgba(255,255,255,0)', 'rgba(255,255,255,0.45)', 'rgba(255,255,255,0)']}
